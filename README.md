\# Анализ событий информационной безопасности



\## Описание проекта



Проект демонстрирует обработку, анализ и визуализацию событий информационной безопасности с использованием Python.



Для работы используются библиотеки Pandas, Matplotlib и Seaborn.



\## Цель проекта



Изучить распределение событий информационной безопасности по типам на основе поля `signature`.



\## Структура проекта



\- `events.json` — набор данных с событиями информационной безопасности.

\- `generate\_events.py` — скрипт генерации тестовых событий.

\- `analysis.py` — загрузка, анализ и визуализация данных.

\- `requirements.txt` — список необходимых библиотек.



\## Используемые технологии



\- Python 3.9

\- Pandas

\- Matplotlib

\- Seaborn

\- JSON



\## Запуск проекта



1\. Клонировать репозиторий.

2\. Создать виртуальное окружение:



&#x20;  ```powershell

&#x20;  py -m venv venv

&#x20;  ```



3\. Активировать виртуальное окружение:



&#x20;  ```powershell

&#x20;  .\\venv\\Scripts\\Activate.ps1

&#x20;  ```



4\. Установить зависимости:



&#x20;  ```powershell

&#x20;  python -m pip install -r requirements.txt

&#x20;  ```



5\. Запустить анализ:



&#x20;  ```powershell

&#x20;  python analysis.py

&#x20;  ```



При необходимости повторно сгенерировать набор данных:



```powershell

python generate\_events.py

```



\## Результаты анализа



В ходе выполнения проекта:



\- JSON-файл загружается в DataFrame с помощью Pandas.

\- Выполняется анализ распределения событий по полю `signature`.

\- Строится горизонтальная столбчатая диаграмма с использованием Seaborn.

\- График сохраняется в файл `events\_distribution.png`.



\## Результат



Набор данных содержит 100 событий информационной безопасности шести типов.



Наибольшее количество событий в тестовом наборе относится к категории `SSH Brute Force Attempt`.
